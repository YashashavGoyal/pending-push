Building High-Throughput Web Applications with Fastify and Next.js 15

Alex Rivera
Staff Engineer @ BlogSphere • 7 min read

Node.js backends frequently bottleneck on JSON serialization overhead and bloated middleware chains. By pairing Fastify 5.x with schema compilation via TypeBox/Zod and Next.js 15 Server Components, we achieved a 3.8x throughput increase with zero extra infrastructure.

💡
Key Takeaway: Schema-based validation doesn't just protect endpoints—it enables Fastify to compile ultra-fast serialization functions under the hood using fast-json-stringify.

1. The 4-Tier Layered Architecture

To maintain absolute decoupling between our HTTP transport layer and domain logic, we enforce a strict 4-tier structure:

  • Routes: Fastify plugins defining HTTP methods, URLs, and OpenAPI/Swagger contracts.
  • Controllers: Unpacks requests, handles parameter validation, and delegates to services.
  • Services: Pure business logic, authorization policies, and orchestrations.
  • Repositories: Direct database adapters (MongoDB, PostgreSQL, or in-memory fixtures).

2. Type-Safe Route Registration

Here is how routes are configured with preHandler validation middleware:

typescript • src/routes/post.routes.ts 
import { FastifyInstance } from 'fastify';
import { PostController } from '../controllers/post.controller';
import { authPreHandler } from '../middleware/auth.middleware';

export const registerPostRoutes = (
  fastify: FastifyInstance, 
  controller: PostController
): void => {
  fastify.post(
    '/new',
    {
      preHandler: [authPreHandler],
      schema: {
        description: 'Create a new markdown blog post',
        tags: ['Posts'],
      }
    },
    controller.create
  );
};

3. Git Diff: Migrating from Legacy Express

Notice how much boilerplate is eliminated when moving to Fastify's structured plugin architecture:

diff • server.ts Migration 
app.use(express.json());


app.use('/api/posts', postRoutes);


await fastify.register(fastifySwagger);


await fastify.register(registerPostRoutes, { prefix: '/api/posts' });

4. Performance Benchmarks

We benchmarked standard read endpoints under 2,000 concurrent requests with autocannon:

Metric Legacy Client/Server Fastify + Next.js 15
Req/Sec 3,420 req/s 14,890 req/s
Latency (p99) 88 ms 12 ms
