Building a High-Performance Public Insights Heatmap from Scratch

Learn how to visualize readership activity grids using pure CSS Grid, minimal DOM memory overhead, and Fastify aggregation endpoints.

Prerequisites
  • Node.js 18+ and a running Fastify 5.x or Next.js 15 instance.
  • Basic familiarity with CSS Grid (grid-template-columns: repeat(26, 1fr)).
  • Terminal with git initialized.
Step 01 Est. 5 mins

Define the CSS Grid Activity Heatmap Layout

To eliminate bloated third-party charting libraries, construct the 52-week activity grid with semantic HTML divs and CSS Grid.

styles/heatmap.css 
.activity-grid-52 {
  display: grid;
  grid-template-columns: repeat(26, 1fr);
  gap: 4px;
}

.activity-cell {
  aspect-ratio: 1;
  border-radius: 2px;
  background-color: var(--bg-subtle);
  border: 1px solid var(--border-subtle);
  transition: transform 120ms ease;
}

.activity-cell:hover {
  transform: scale(1.3);
  outline: 2px solid var(--status-emerald);
}
