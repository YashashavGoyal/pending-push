Building a High-Performance Public Insights Heatmap from Scratch

Learn how to visualize readership activity grids using pure CSS Grid, minimal DOM memory overhead, and Fastify aggregation endpoints.

Alex Rivera
Updated Nov 15, 2026 • 1,450 completions
Tutorial Progress Checklist 0 of 4 steps completed (0%)

Prerequisites & Setup

  • Basic knowledge of CSS Grid (grid-template-columns: repeat(16, 1fr)).
  • Node.js 18+ and a running Fastify or Next.js server instance.
  • Estimated completion time: 20–25 minutes.
Step 1 of 4 Est. 5 mins

Define the CSS Grid Activity Heatmap Layout

To avoid complex charting libraries (which add 150kb+ to the client bundle), we can render the 52-week activity grid with semantic HTML divs and CSS Grid.

css • heatmap.css 
.heatmap-grid {
  display: grid;
  grid-template-columns: repeat(16, 1fr);
  gap: 4px;
}

.heatmap-cell {
  aspect-ratio: 1;
  border-radius: 3px;
  background-color: var(--bg-tertiary);
  transition: transform 150ms ease;
}

.heatmap-cell:hover {
  transform: scale(1.25);
  outline: 2px solid var(--accent-emerald);
}
Step 2 of 4 Est. 6 mins

Calculate 4-Tier Activity Intensity Levels

Map daily article views or commits into 4 distinct color intensities using quantile bins.

typescript • heatmap-utils.ts 
export function getIntensityLevel(count: number): 'level-0' | 'level-1' | 'level-2' | 'level-3' | 'level-4' {
  if (count === 0) return 'level-0';
  if (count < 3) return 'level-1';
  if (count < 8) return 'level-2';
  if (count < 15) return 'level-3';
  return 'level-4';
}
