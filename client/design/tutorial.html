Building a High-Performance Public Insights Heatmap from Scratch

Learn how to visualize readership activity grids using pure CSS Grid, minimal DOM memory overhead, and Fastify aggregation endpoints.

Prerequisites
  • Node.js 18+ and a running Fastify 5.x or Next.js 15 app.
  • Basic knowledge of CSS Grid layout principles.
  • An open terminal window.
Step 01 Est. 5 mins

Define the CSS Grid Activity Heatmap Layout

To eliminate heavy third-party charting libraries (which add 150kb+ to your bundle), construct the 52-week activity grid with semantic HTML divs and CSS Grid.

styles/heatmap.css 
.activity-grid-52 {
  display: grid;
  grid-template-columns: repeat(26, 1fr);
  gap: 6px;
}

.activity-cell {
  aspect-ratio: 1;
  border-radius: 4px;
  background-color: var(--bg-subtle);
  transition: transform 150ms ease;
}

.activity-cell:hover {
  transform: scale(1.35);
  outline: 2px solid var(--accent-sage);
}

Map raw event counts into 4 distinct color intensities using quantile bins.

Fastify Backend Aggregation Endpoint
